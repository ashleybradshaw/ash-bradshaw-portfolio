## THE PRODUCT CHALLENGE

Savings tools often arrive as extra screens, extra choices, and extra guilt.

The brief was to add financial capability without adding cognitive load to an already data-dense money-management surface.

## SYSTEM & EXECUTION

The concept treated savings as a quiet, low-load overlay on existing behaviours rather than a new destination.

By restraining interaction density and using a character-led visual system, the prompts, language, and visual hierarchy stayed entirely secondary to the user's primary money job.

## IMPACT

- Savings introduced as a frictionless layer, not a parallel product that required user re-education.
- Speculative concept successfully pressure-tested UI hierarchy and interaction density.
- Visual token system designed to sit seamlessly inside an existing money-management brand.
