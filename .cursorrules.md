# ASH BRADSHAW - DESIGN SYSTEM & BUILD RULES

## 1. Tech Stack
- Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, lucide-react.
- STRICT RULE: Use `next/image` for all images to ensure automatic WebP optimisation and lazy loading. Use solid color placeholders (e.g., `bg-neutral-200`) if assets are missing.

## 2. Typography
- Display/Headings: `Palanquin Dark` (Weights: 400, 500, 600, 700).
- Body/UI: `Plus Jakarta Sans` (Weights: 400, 500, 600, 700).
- Implementation: Use `next/font/google` to load these efficiently.

## 3. Colour Tokens (Tailwind Config Extension)
- Brand Red (Main): `#FF0E00` -> `bg-brand-red`
- Brand Blue (Sub): `#13014C` -> `bg-brand-blue`
- Electric Red Hover: `#D40B00`
- Deep Blue Hover: `#20086B`
- Calm Tint Light: `#F7F6F9` -> `bg-calm-light`
- Calm Tint Gray: `#E8E6F0`
- Text Dark: `#0A0127` -> `text-dark`
- Text Light: `#FFFFFF`
- Accent Cream: `#FFF9E6`

## 4. UI & Interaction Rules
- Buttons: Default to `bg-brand-blue text-white`. Hover state translates Y by -2px (`hover:-translate-y-0.5`) with a 200ms ease transition.
- Focus Rings: Use a 3px solid `#FF0E00` ring with a 2px offset for accessibility.
- Animations: Keep subtle. Do not over-animate. Rely on Framer Motion for layout transitions.

## 5. Code Quality
- Write modular, reusable React server and client components.
- Perform self-audits to remove unused imports, dead code, and redundant CSS classes.
